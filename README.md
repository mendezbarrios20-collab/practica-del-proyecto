# PerfectFit Bowl - Mi Emprendimiento Digital

Cafetería fitness enfocada en ofrecer opciones de alimentación prácticas, nutritivas y listas para consumir, diseñadas específicamente para acompañar las rutinas ocupadas de nuestros clientes.

## 🚀 Características del Proyecto
* **Landing Page:** Presentación de la marca y propuesta de valor.
* **Catálogo Inteligente:** Organizado por momentos del día (Desayunos, Snacks, Pre-Entreno y Post-Entreno).
* **Integración con IA:** Chatbot de atención y recomendador de platos según preferencias.
* **Panel de Administración:** Gestión interna de productos y mensajes.

## 🛠️ Tecnologías que se utilizarán
* HTML5 (Estructura semántica)
* CSS3 (Diseño responsive y animaciones)
* JavaScript / React (Lógica y Frontend moderno)
* Integración de Inteligencia Artificial
